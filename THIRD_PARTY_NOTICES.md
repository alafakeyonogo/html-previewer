# 第三方依赖

以下浏览器依赖随目录提供，不需要在使用时从 CDN 获取：

- Lucide React 1.14.0 图标：从原项目的图标节点复制为 `icons.svg`，许可见 `vendor/Lucide-LICENSE`。

- DOMPurify 3.4.2：`vendor/purify.min.js`；许可见 `vendor/DOMPurify-LICENSE`。原项目：<https://github.com/cure53/DOMPurify>。
- html2canvas 1.4.1：`vendor/html2canvas.min.js`；文件头保留作者和 MIT 许可声明。原项目：<https://github.com/niklasvh/html2canvas>。
- Tailwind CSS 3.4.17 浏览器运行版本：`vendor/tailwindcss-3.4.17.js`；原项目：<https://github.com/tailwindlabs/tailwindcss>。保留文件内的第三方许可声明。
